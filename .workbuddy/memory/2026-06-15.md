# 2026-06-15 工作日志

## 科普馆预约查询 - handleConfirm/handleCancel 添加确认弹窗

- `handleConfirm`：调用前弹出 `ElMessageBox.confirm`，提示「确认该预约已参观？操作后状态将变更为「已使用」」，确认后再调接口，用户取消则静默处理
- `handleCancel`：调用前弹出 `ElMessageBox.confirm`，提示「确认取消该预约？不可恢复」，确认按钮使用 danger 样式，用户取消则静默处理
- 两个方法均使用 `.catch(() => {})` 捕获用户点取消时 Promise reject，避免控制台报错
